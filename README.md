# 角色卡编辑器

SillyTavern 扩展插件：和 AI 讨论角色卡与世界书，把修改建议一键应用到角色卡和世界书。

> 插件前身是「开场白生成器」，开场白生成页和状态栏页已移除。为了让已有设置和会话继续可用，
> 文件夹名、设置键（`first-message-generator`）和历史文件名都沿用旧名字。

## 功能

- **讨论角色卡**：AI 能看到当前角色卡的全部字段和已选世界书条目，可以多轮讨论设定。
- **整段修改**：AI 输出 `[EDIT:字段名]`，卡片上对比当前值，点「应用」写入角色卡。
- **局部修改**：只改一部分时，AI 输出 `[PATCH:字段名]` 或 `[PATCH:wi:UID]`，里面是
  `<<<<<<< SEARCH` / `=======` / `>>>>>>> REPLACE` 替换块，只写要改的句子。应用时按最新内容定位：
  先精确匹配，再忽略空白和全半角标点匹配；找不到或匹配到多处时不写入。
- **世界书条目**：AI 输出 `[WORLDBOOK_ENTRY]` 新建或更新条目；更新时没写的字段沿用原值。
  写入后回读服务器确认，失败会报错而不是假成功。
- **条目选择**：选择 AI 能看到的世界书条目；装了 ST-Grouping 时按它的世界书分组显示。
- **最近会话**：每个角色保留最近 3 个讨论会话，存在 `data/<用户>/user/files/first-message-generator-history.json`，
  不占 settings.json。
- **全部应用**：一条回复里有多个修改时，可以按顺序一次应用。
- **独立 API 配置**：支持 OpenAI / Gemini 格式，可保存多套方案切换。

## 使用方法

1. 在 ST 里选中角色，点击扩展菜单中的「角色卡编辑器」。
2. 在「选择条目」里勾选要让 AI 参考或修改的世界书条目。
3. 在输入框里讨论，或直接提出修改要求，例如“把描述里关于职业的那句改成……”。
4. 在回复里的卡片上检查改动，点「应用」或「全部应用」。
